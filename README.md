I'm 18 and I build hardware in my free time. I design the PCB, write the firmware, and 3D print a case when the project needs one. I like the part where an idea goes from a schematic to a board that actually works. It usually takes a few revisions and the odd bodge wire, but that's part of the process.

I work mainly in EasyEDA Pro and C/C++. I've built flight controllers, macropads, development boards, and a flight computer for model rockets. MACROPeX was one of the first PCBs I designed, and it's still one of my favorite projects because I learned most of the process while making it.

### projects

| project | what it is |
| :--- | :--- |
| **[B2-stealth-FC](https://github.com/omruk5689-dev/B2-stealth-FC)** | STM32F722 flight controller for RC planes. It has an ICM-20689 IMU, DJI O4 support, and plenty of UARTs. |
| **[STAR-FLIGHT](https://github.com/omruk5689-dev/STAR-FLIGHT)** | RP2350 flight computer for model rockets. It has an IMU, barometer, CAN bus, and onboard flash logging. |
| **[MACROPeX](https://github.com/omruk5689-dev/MACROPeX)** | Open-source RP2040 macropad with 9 keys, 3 encoders, RGB, and remappable firmware. |
| **[PIXO](https://github.com/omruk5689-dev/PIXO)** | Small ATmega328P dev board with USB-C and an onboard CH340C. It's my take on the Arduino Uno. |
| **[DK-32](https://github.com/omruk5689-dev/DK-32)** | ESP32 dev board shaped like a Batarang. I wanted to see if I could fit a working board into that shape. |

### tools I use

- **PCB design:** EasyEDA Pro, schematic capture, multi-layer layout, 3D preview, BOM and Gerber export
- **Firmware:** C, C++, Arduino IDE, PlatformIO, ESP-IDF, QMK, STM32, I2C, SPI, UART, CAN
- **Hardware:** STM32F1/F7, RP2040/RP2350, ESP32, ATmega328P, IMUs, barometers, USB-C, power supplies
- **Workflow:** Git, GitHub, VS Code, Linux, Python, Markdown
- **Bench:** soldering, hot-air rework, logic analyzer, 3D printing
